# 背景音乐放这里

当前已内置 `bgm.mp3`（羊了个羊 BGM，2 分 37 秒，128kbps，2.4MB，来自爱给网 aigei.com）。

想换歌就直接覆盖 `bgm.mp3`，或者删掉它换成下表里的其他格式。

文件名按下表的优先级取第一个能读到的：

| 优先级 | 文件名 | 说明 |
| --- | --- | --- |
| 1 | `bgm.mp3` | 最通用，推荐 |
| 2 | `bgm.ogg` | 体积更小，Safari 旧版不支持 |
| 3 | `bgm.m4a` | 苹果生态友好 |
| 4 | `bgm.wav` | 无损但文件大，仅当没有别的格式时用 |

只要文件名对，页面刷新就会自动循环播放，顶栏按钮可以随时静音。
放进来之前，顶栏会显示「🔇 无音乐」，游戏照常玩，不会有任何报错。

## 挑音乐的几个建议

- **必须是能无缝循环的曲子**，否则每首都接回去会有明显断点。找不到专门的无缝循环版，可以选前奏很轻、结尾自然收住的曲子。
- **体积控制在 2MB 以内**。GitHub Pages 单文件上限 100MB，但手机流量加载会慢。
- **注意版权**。公开部署等于公开发布，建议用 CC0 / 可商用免费素材，例如：
  - Pixabay Music（免费，多数无需署名）
  - Kevin MacLeod / incompetech（CC BY，需在页面注明出处）
  - 自己用 LMMS、BeepBox、Bosca Ceoil 做一段 8-bit 循环
- 如果用了需要署名的素材，记得在 `index.html` 底部或 README 里写上作者和许可，这是许可要求。

## 想改成点开才播 / 只在关卡里播

播放逻辑在 `index.html` 里搜 `【新增 2】背景音乐`，集中在
`initMusic()`、`toggleMusic()`、`fadeBgm()` 三个函数里，改起来不难。
